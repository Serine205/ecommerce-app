# 🧵 Boutique Marron – E-Commerce React App

Projet réalisé dans le cadre du module **Développement Web**, 2e année Informatique, Université d'Alger.

Cette application est une boutique de vêtements en ligne avec un thème visuel chaleureux (marron).  
Les utilisateurs peuvent consulter les produits, lire les avis, ajouter au panier, ajuster les quantités et simuler un achat.
